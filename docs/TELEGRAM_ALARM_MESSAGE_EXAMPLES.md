# 다분할 매매 전략 – 텔레그램 알람 메시지 예시

알람 시 텔레그램으로 오는 메시지는 **전반전 / 후반전 / 쿼터 손절 모드**에 따라 DAILY EXECUTION 블록만 달라집니다.  
아래는 각 경우의 수별 **한국어(ko)** 예시입니다.

---

## 공통 구조

모든 메시지는 다음 형태입니다.

```
🔔 BTD 매매 알람

{본문 문구}

⏰ KST 15:00

📋 DAILY EXECUTION
{포트폴리오별 일별 매매 실행 요약}
```

- **본문**: 예) "설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요." 또는 커스텀 문구
- **DAILY EXECUTION**: 다분할이면 **전반전 / 후반전 / 쿼터 손절**에 따라 아래와 같이 바뀝니다.

---

## 1. 전반전 (First Half)

**조건**: \( 0.5 \le T < a/2 \) (예: a=40이면 T=0.5~19)

**예시 메시지**

```
🔔 BTD 매매 알람

설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요.

⏰ KST 15:00

📋 DAILY EXECUTION
📌 나의 다분할 포트폴리오
- 다분할 매매법
- 알람 시간 (KST): 15:00, 16:00
- LOC 매수1: 185.50 / 26주
- LOC 매수2: 182.10 / 27주
- LOC 매도: 183.10 / 32주
- 지정가 매도: 195.00 / 96주
```

- LOC 매수1·2, LOC 매도, 지정가 매도 가격/수량이 모두 표시됩니다.

---

## 2. 후반전 (Second Half)

**조건**: \( a/2 \le T < a-1 \) (예: a=40이면 T=20~38)

**예시 메시지**

```
🔔 BTD 매매 알람

설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요.

⏰ KST 15:00

📋 DAILY EXECUTION
📌 나의 다분할 포트폴리오
- 다분할 매매법
- 알람 시간 (KST): 15:00, 16:00
- LOC 매수2: 178.20 / 55주
- LOC 매도: 179.20 / 65주
- 지정가 매도: 195.00 / 195주
```

- 후반전은 LOC 매수는 1개(LOC 매수2 기준가), LOC 매도·지정가 매도만 표시됩니다.

---

## 3. 쿼터 손절 모드 – MOC 매도 전 (진입 대기)

**조건**: \( T > a-1 \) 이고, **아직 MOC 매도를 하지 않은 상태** (쿼터 모드 진입 직전)

**예시 메시지**

```
🔔 BTD 매매 알람

설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요.

⏰ KST 15:00

📋 DAILY EXECUTION
📌 나의 다분할 포트폴리오
- 다분할 매매법
- 알람 시간 (KST): 15:00, 16:00
- MOC 매도: 125.50 주
- MOC 매도 하여 쿼터 손절 모드 시작하세요
```

- 보유 수량의 약 25%를 MOC 매도하라는 수량만 안내하고, “MOC 매도 하여 쿼터 손절 모드 시작하세요” 문구가 붙습니다.

---

## 4. 쿼터 손절 모드 – MOC 매도 후 (진행 중)

**조건**: 쿼터 모드 플래그 ON + **이미 MOC 매도를 한 상태** (최근 11 영업일 이내 MOC 매도 기록 있음)

**예시 메시지**

```
🔔 BTD 매매 알람

설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요.

⏰ KST 15:00

📋 DAILY EXECUTION
📌 나의 다분할 포트폴리오
- 다분할 매매법
- 알람 시간 (KST): 15:00, 16:00
- 1회 매수금: $1,250.00
- LOC 매수2: 168.50 / 72주
- LOC 매도: 169.50 / 94주
- 지정가 매도: 180.00 / 281주
```

- 쿼터 모드용 1회 매수금과, LOC 매수2 / LOC 매도 / 지정가 매도 가격·수량이 표시됩니다.

---

## 5. 알람만 켜져 있고 상세 계산 없을 때

**조건**: 다분할이지만 당일 주문 상세(가격/수량)를 계산할 수 없는 경우 (예: 보유 없음, 데이터 부족)

**예시 메시지**

```
🔔 BTD 매매 알람

설정하신 매매 알람 시간입니다. 포트폴리오 전략을 확인해 주세요.

⏰ KST 15:00

📋 DAILY EXECUTION
📌 나의 다분할 포트폴리오
- 다분할 매매법
- 알람 시간 (KST): 15:00, 16:00
- 오늘 주문 요약은 앱에서 확인해 주세요.
```

---

## 요약 표

| 구간           | 조건 (T, a)   | DAILY EXECUTION 내용 |
|----------------|---------------|----------------------|
| 전반전         | 0.5 ≤ T < a/2 | LOC 매수1·2, LOC 매도, 지정가 매도 (가격/수량) |
| 후반전         | a/2 ≤ T < a-1 | LOC 매수2, LOC 매도, 지정가 매도 (가격/수량) |
| 쿼터 (MOC 전)  | T > a-1, MOC 미실행 | MOC 매도 수량 + “MOC 매도 하여 쿼터 손절 모드 시작하세요” |
| 쿼터 (MOC 후)  | 쿼터 모드 ON, MOC 실행됨 | 1회 매수금 + LOC 매수2, LOC 매도, 지정가 매도 (가격/수량) |
| 기타           | 계산 불가 등  | “오늘 주문 요약은 앱에서 확인해 주세요.” |

영어(en) 설정 시에는 같은 구조에 `Alarm times (KST)`, `LOC Buy1`, `MOC Sell`, `Execute MOC sell to start quarter stop-loss mode` 등 영어 문구로 치환됩니다.
