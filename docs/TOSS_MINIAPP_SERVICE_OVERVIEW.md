# 토스 미니앱 서비스 개요 — 토스 팀 소개용

> 역할: 시니어 마케팅 관점에서 **미니앱 내에서 실제로 제공되는 구체적인 서비스 내용**을 정리한 문서입니다.  
> 대상: 토스 팀(파트너/검토 담당자)에게 서비스 내용을 전달할 때 참고.

---

## 1. 서비스 한 줄 요약

**BUY THE DIP** — 미국 ETF/레버리지 종목을 대상으로 **“나만의 분할 매수·매도 전략”을 저장하고, 알람으로 실행을 리마인드하며, AI로 매매 내역을 자동 인식·기록하는 투자 관리 미니앱**입니다.

---

## 2. 미니앱 내 주요 화면(탭) 구성

| 탭 | 화면명 | 제공 내용 (미니앱 내 구체적 기능) |
|----|--------|-----------------------------------|
| **대시보드** | 대시보드 | 활성 포트폴리오 목록, 종목별 투자금·수익률·현재 구간, **일별 매매 실행 요약**, 빠른 매매 입력·알람 설정·상세·전략 종료·AI 매매 인식 진입 |
| **시세** | 시세 | 종목별 실시간(캐시) 시세, 차트(가격·MA20·MA60), 시장 상태(미국 휴장일 등), PRO/Premium 구독 시 확장 종목(TSLA, NVDA, MSTR, FNGU, TECL 등) 노출 |
| **투자이력** | 투자이력 | 종료된 포트폴리오 목록, 종목·투자금·수익·수익률·정산 상세 보기 |
| **멤버십** | 멤버십 | FREE / PRO / PREMIUM 요금제 비교, 토스페이 결제(미니앱) 연동으로 PRO 구독 결제 |
| **이용약관 / 개인정보처리방침** | 약관·개인정보 | 앱 내 탭으로 열람, 토스 미니앱 고객센터 링크(Footer) |

※ 백테스트 탭은 웹과 동일하게 제공되나, 미니앱 UX에서는 하단 네비에 포함되지 않고 진입 경로가 제한될 수 있음.

## 3. 미니앱 내 구체적 서비스 기능

### 3.1 포트폴리오·전략 관리

- **포트폴리오 생성**: 전략 엔진 선택 후 파라미터 설정 → 단일 포트폴리오로 저장.
- **지원 전략 타입** (미니앱 내 동일):
  - **다분할 매매법**: 목표 수익률(A%), 총 분할 횟수(T), 1회 금액 등 설정. LOC/MOC 기준점·매도 비율(1/4 LOC, 3/4 지정가) 등으로 일별 실행 가이드.
  - **이평선 구간매수**: 단기/장기 이평선(MA) 구간 + RSI·정배열 옵션. 구간별 매수·익절 규칙 설정.
- **포트폴리오별 기능**:  
  빠른 매매 입력, 상세 매매 실행 기록, **알람 설정(시간대 선택)**, **AI 매매 인식(스크린샷 업로드 → 자동 매매 내역 추출)**, 전략 종료(정산)·삭제.

### 3.2 알람·리마인드

- 포트폴리오 단위로 **알람 On/Off + 알람 받을 시간(KST)** 설정.
- 티어별 **알람 슬롯 한도**: FREE 2개, PRO 10개, PREMIUM 40개.
- (PRO 이상) **텔레그램 연동** 시 상세 알림 메시지(다분할/이평선 요약, LOC·MOC·지정가 주문 라인 등) 발송.

### 3.3 시세·종목

- **무료 구간**: SPY, SSO, UPRO, QQQ, QLD, TQQQ, SOXX, USD, SOXL, STRC, BIL, ICSH, SGOV 등 **13개 코어 ETF**.
- **PRO/Premium**: TSLA, TSLL, NVDA, NVDL, GOOGL, GGLL, PLTR, PTIR, COIN, CONL, MSTR, MSTX, BMNR, FNGU, TECL, BULZ, GDXU 등 **17개 추가 종목** 해금.
- 시세 탭: 종목별 가격·MA20·MA60 차트, 휴장일 반영.

### 3.4 AI 매매 인식

- 증권 앱 **체결 화면 스크린샷** 업로드(또는 붙여넣기) → **Gemini 기반 이미지 인식**으로 매수/매도 종목·가격·수량 추출 → 사용자 확인 후 포트폴리오에 **매매 1건으로 저장**.
- 티어별 한도: FREE 1회/일, PRO 50회/월, PREMIUM 무제한(정책상).

### 3.5 백테스트

- **이평선 구간매수** / **다분할 매매법** 전략 선택 → 파라미터 입력 → (엔진 연동 시) 과거 데이터 기반 수익률·CAGR·MDD·승률·샤프 등 결과 표시.
- 일별 사용 한도: FREE 2회, PRO 5회, PREMIUM 10회(UI 표기 기준, 현재 백테스트 엔진 연동은 진행 중일 수 있음).

### 3.6 인증·결제(미니앱)

- **로그인**: 이메일/비밀번호 외, 미니앱 내 **“Toss로 계속하기”** 제공(토스 인증 코드 → BFF 경유 세션 발급).
- **멤버십 결제**: PRO 플랜 선택 시 **토스페이만** 사용(미니앱). PG(포트원 등) 결제 수단 선택 UI는 미니앱에서 비노출, "토스페이로 결제됩니다" 안내. 결제 검증은 BFF 경유.

## 5. 미니앱 전용 노출·경험

- **랜딩/CTA**: “나만의 BUY THE DIP 전략을 저장하고 관리하세요” + 로그인/회원가입 유도.
- **Footer**: 토스 환경에서 **토스 미니앱 고객센터** 버튼(TDS 스타일), 이용약관·개인정보처리방침·환불규정 링크.
- **UI**: 토스 앱 내일 때 **TDS(Toss Design System)** 적용(버튼·모달·폼 등), 웹과 동일 기능에 디자인만 토스 룩앤필로 통일.

## 6. 토스 팀에 전달 시 강조 포인트(마케팅 관점)

1. **타깃**: 미국 ETF/레버리지 분할 매수 전략을 **체계적으로 실행·기록**하고 싶은 개인 투자자.
2. **차별점**: 전략 템플릿(다분할·이평선 구간매수) + **알람 리마인드** + **AI 체결 인식**을 하나의 플로우로 제공.
3. **미니앱 가치**: 토스 로그인·토스페이 결제로 진입·결제 문턱 감소, TDS로 토스 앱 내 일관된 경험.
4. **수익화**: PRO/PREMIUM 구독(월 정기 결제), 미니앱 내 토스페이 연동.
