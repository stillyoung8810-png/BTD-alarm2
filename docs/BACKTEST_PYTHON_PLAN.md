# 백테스트 Python 연산 계획 (단계별)

Supabase에서 주가 데이터를 불러와 이평선을 계산하고, 이평선 구간매수 전략 백테스트를 수행하기 위한 **계획**만 단계별로 정리합니다. (실제 코드 작성은 다음 단계에서 진행)

---

## 전제

- **데이터 소스**: Supabase 테이블 `stock_prices`
  - 컬럼: `symbol`, `trade_date`, `close` (그 외 `fetched_at` 등)
  - 복합 유니크: `(symbol, trade_date)`
- **이평선·RSI**: Supabase에는 **종가(close)만** 저장되어 있음. 이동평균(MA)·RSI는 **Python(Pandas)에서 계산**해야 함.
- **백테스트 파라미터**: 프론트의 `BacktestParamsMa`와 동일 (기준주식, RSI 사용 여부, 구간 1·2·3의 이평 기간·종목·RSI·중간 익절 여부·%, 1회 매수 금액, 백테스트 개월 수, 수수료율).

---

## 1단계: Supabase에서 어떤 데이터를 가져올지 정하기

- **필요 종목**
  - **기준 주식 1개**: `baseStock` (구간 판정용 — 이 종목의 종가로 구간 1/2/3 판별)
  - **매수 종목 3개**: `ma1Stock`, `ma2Stock`, `ma3Stock` (구간별로 실제 매수할 종목)
  - 중복 제거 후 최대 4개 symbol.
- **기간**
  - 백테스트 기간 `months` (예: 24개월). **끝일** = “오늘” 또는 “가장 최근 거래일”, **시작일** = 끝일 - months 개월.
- **쿼리**
  - 위 symbol들에 대해 `trade_date`가 [시작일, 끝일] 안에 있는 행만 조회.
  - 컬럼: `symbol`, `trade_date`, `close` 만 있으면 됨.
  - 정렬: `symbol`, `trade_date` 오름차순 (이후 Pandas에서 일별 시뮬레이션하기 좋게).

---

## 2단계: Supabase 클라이언트로 데이터 조회

- Lambda 환경 변수(또는 Event)에서 **Supabase URL**과 **anon key 또는 service_role key** 읽기.
- Supabase Python 클라이언트로 `stock_prices` 테이블에 접근.
- 1단계에서 정한 symbol·기간으로 **REST API 또는 .from('stock_prices').select(...)** 로 한 번에(또는 종목별로) 조회.
- 응답을 **리스트/딕셔너리** 형태로 받아 두기 (아직 Pandas 변환은 다음 단계).

---

## 3단계: Pandas DataFrame으로 넣고 정리

- 조회 결과를 **Pandas DataFrame**으로 변환.
  - 컬럼: `symbol`, `trade_date`, `close`.
- **trade_date**를 datetime 또는 “날짜만” 타입으로 통일.
- **종목별·날짜순** 정렬 유지 (같은 날짜에 여러 종목이 한 행씩 있어도 되고, 나중에 pivot하거나 group by해도 됨).
- 결측(close가 null/0 등) 제거 또는 보간 방침 정하기 (예: 해당 행 제외).

---

## 4단계: 기준 주식(baseStock)으로 이평선 계산

- **기준 주식** 데이터만 필터 (baseStock의 `symbol` 행만).
- **날짜 오름차순**으로 정렬된 종가 시계열에 대해:
  - **구간 1 이평**: 기간 `ma1Period` (예: 20일) → 이동평균 한 시리즈.
  - **구간 2 이평**: 기간 `ma2Period1`, `ma2Period2` (예: 20, 60) → 두 개의 이동평균 시리즈.
  - **구간 3 이평**: 기간 `ma3Period` (예: 60일) → 이동평균 한 시리즈.
- 이동평균은 **과거 N일 종가의 평균** (해당일 포함 여부는 기존 앱 로직과 맞추기 — 보통 해당일 포함 rolling mean).
- 20/60/120이 아닌 기간(예: 30, 50)도 **Pandas rolling + mean**으로 동일하게 계산.

---

## 5단계: 일별 “오늘의 구간” 판정

- **백테스트 기간의 거래일**을 하나씩 순회 (또는 DataFrame의 trade_date 유니크 목록).
- 각 날짜에 대해:
  - 그날의 **기준 주식 종가** 한 개.
  - 그날까지 계산된 **기준 주식의** 이평선값들 (ma1, ma2-low, ma2-high, ma3).
- **판정 규칙** (기존 `determineActiveSection` 로직과 동일):
  - **구간 3**: 기준 종가 < ma3 이평선 → 구간 3.
  - **구간 2**: 기준 종가가 ma2 두 이평선 사이(이하) → 구간 2.
  - **구간 1**: 기준 종가 >= ma1 이평선 → 구간 1.
- 그날의 **활성 구간(1, 2, 3)** 과 **매수할 종목**(ma1Stock / ma2Stock / ma3Stock)을 결정.

---

## 6단계: (선택) RSI 사용 시 RSI 계산 및 매수 스킵

- **RSI 사용**이 켜져 있으면:
  - **기준 주식**의 일별 종가 시계열로 **RSI(14)** 계산 (기존 앱의 Wilder RSI와 동일 공식 권장).
  - 각 날짜에 대해 “오늘의 구간”이 정해진 뒤, **해당 구간의 rsiThreshold**(ma1Rsi / ma2Rsi / ma3Rsi)와 비교.
  - **오늘 RSI > 해당 구간 rsiThreshold** 이면 그날은 **매수하지 않음**(관망).
- RSI 미사용이면 이 단계 생략.

---

## 7단계: 일별 매수 시뮬레이션 (포지션·현금·수수료)

- **초기**: 현금 = 0 또는 “초기 투자금” (정책에 따라), 보유 종목 수량 = 0.
- **거래일 순서대로**:
  - 5·6단계에서 정한 “오늘의 구간”과 “매수 종목”을 사용.
  - 매수할 날이면: **1회 매수 금액**(dailyBuyAmount)만큼 그날 종가로 수량 산정, **수수료**(feeRate %) 차감.
  - **중간 익절**이 켜진 구간이면: 해당 구간 매수분에 대해 **목표 수익률(partialProfitTargetPct)** 도달 시 매도 규칙 적용 (구간별 평단가·수량 추적 필요).
- **보유 수량·평단가·현금**을 날짜마다 갱신하고, **매매 이력**(날짜, 종목, 매수/매도, 가격, 수량, 수수료)을 남김.

---

## 8단계: 결과 지표 계산 (자산 곡선, MDD, CAGR, 승률 등)

- **자산 곡선**: 각 날짜(또는 매매 발생일)의 “현금 + 보유 종목 시가총액”을 나열 → `equityCurve`.
- **누적 수익률**: (최종 자산 - 총 투입) / 총 투입 × 100.
- **CAGR**: 기간(년)으로 연환산.
- **MDD**: 자산 곡선의 고점 대비 최대 낙폭(%) → `drawdownSeries` (날짜별 낙폭).
- **승률**: 매도 발생 건 중 “이익 낸 건” 비율.
- **샤프 지수**: (수익률 시리즈의 평균 - 무위험) / 표준편차, 연환산 등 기존 정의에 맞춤.
- **평균 보유 기간**: 매수일→매도일 일수 평균.

---

## 9단계: Lambda 응답 형식 (JSON)

- 프론트의 `BacktestResult`와 맞추기:
  - `totalReturnPct`, `cagrPct`, `mddPct`, `winRatePct`, `sharpeRatio`, `avgHoldingDays`
  - `equityCurve`: `[{ date, value }, ...]`
  - `drawdownSeries`: `[{ date, drawdown }, ...]`
- Lambda 핸들러는 **Event(파라미터)** 받아서 위 1~8단계 실행 후, 이 JSON을 반환.

---

## 10단계: 정리 — 코드 작성 시 순서

1. **입력 파싱**: Event에서 전략 ID, 파라미터(BacktestParamsMa), Supabase URL/키 읽기.  
2. **Supabase 조회**: 1·2단계.  
3. **DataFrame 정리**: 3단계.  
4. **이평선 계산**: 4단계.  
5. **일별 구간 판정**: 5단계.  
6. **RSI 계산·스킵**: 6단계 (옵션).  
7. **매수/매도 시뮬레이션**: 7단계.  
8. **지표·자산 곡선·낙폭 계산**: 8단계.  
9. **JSON 반환**: 9단계.

이 순서대로 구현하면, Supabase 데이터로 이평선을 계산하는 백테스트 파이썬 코드를 체계적으로 붙일 수 있습니다.
