# 이동평균선 구간 전략(MA Strategy) — NotebookLM 지식 문서

> **문서 목적:** 포트폴리오 생성 모달과 전략 상세 설명 모달에 사용할 문구를 만들 때, NotebookLM이 우리 앱의 실제 MA Strategy 비즈니스 로직을 정확히 이해하도록 돕는 자료입니다.  
> **중요:** 이 앱은 증권사에 주문을 자동 제출하거나 체결시키는 자동매매 봇이 아닙니다. MA Strategy도 동일하게, 현재 구간과 매수·관망·중간익절 가이드를 계산해 보여주는 투자 기록장 겸 주문 참고 도구입니다.

---

## 1. 전략의 핵심 개념 (Core Concept)

이동평균선 구간 전략은 기준 종목의 현재 가격이 두 개의 이동평균선 위, 사이, 아래 중 어디에 있는지를 보고 시장 상태를 3개 구간으로 나눈 뒤, 각 구간에 미리 지정한 종목을 매수 대상으로 안내하는 전략입니다.

한 줄로 말하면, **기준 종목 하나로 시장의 위치를 판정하고, 판정된 구간에 맞는 종목을 골라 매수 가이드를 내는 전략**입니다.

### 기본 작동 원리

1. 사용자가 기준 종목(`ma0.stock`)과 두 이동평균 기간(`maAPeriod`, `maBPeriod`)을 정합니다.
2. 시스템은 기준 종목의 현재가와 두 이동평균값을 비교합니다.
3. 현재가가 두 이동평균선보다 높으면 구간 1, 두 이동평균선 사이에 있으면 구간 2, 두 이동평균선보다 낮으면 구간 3으로 판단합니다.
4. 활성 구간이 정해지면 해당 구간에 연결된 종목을 오늘의 매수 후보로 보여줍니다.
5. RSI 또는 정배열 조건이 켜져 있으면, 구간은 그대로 유지하되 매수 안내가 "관망"으로 바뀔 수 있습니다.
6. 중간익절 조건이 켜진 구간은 활성 구간 여부와 별개로, 보유 종목의 수익률이 목표에 도달했는지 매번 확인합니다.

### ma0와 ma1/ma2/ma3을 나누는 이유

`ma0`는 **시장 상태를 판정하는 기준 종목**입니다. 앱은 `ma0.stock`의 현재가, 이동평균선, RSI를 사용해 "지금 시장이 어느 구간인가"를 판단합니다.

`ma1`, `ma2`, `ma3`은 **구간별 행동 대상 종목**입니다. 구간 1이면 `ma1.stock`, 구간 2이면 `ma2.stock`, 구간 3이면 `ma3.stock`이 매수 대상으로 안내됩니다.

이렇게 나누면 기준 지표는 하나로 통일하면서도, 시장 위치에 따라 서로 다른 성격의 종목을 배정할 수 있습니다. 예를 들어 기본 설정은 기준 종목과 구간 1이 `QQQ`, 구간 2가 `QLD`, 구간 3이 `TQQQ`입니다. 즉, 시장이 강할 때는 상대적으로 안정적인 종목, 시장이 낮은 구간에 있을 때는 더 공격적인 종목을 배치하는 식의 설계가 가능합니다.

중요한 점은 **구간 판정에는 항상 `ma0.stock`만 사용한다는 것**입니다. `ma1`, `ma2`, `ma3`의 가격은 구간 판정용이 아니라, 해당 구간 종목의 중간익절 수익률을 계산할 때 사용됩니다.

## 2. 필수 입력 파라미터 (User Inputs)

### 포트폴리오 공통 입력

| 설정값 | 의미 | 주요 제약 |
|---|---|---|
| 포트폴리오 이름 | 사용자가 식별하는 전략 이름 | 빈 값 불가, 최대 100자 |
| 1회 매수 금액 | 사용자가 한 번 매수할 때 참고하는 예산 | 1달러 이상 1,000,000달러 이하 |
| 수수료율 | 거래 기록과 계산에 반영되는 수수료율 | 유효한 숫자여야 하며 앱 검증 범위 안이어야 함 |

MA 구간 판정 자체는 1회 매수 금액이나 수수료율로 바뀌지 않습니다. 이 값들은 포트폴리오 생성, 거래 기록, 평가금액, 백테스트 등 주변 계산에 사용됩니다.

### ma0: 기준 종목과 전역 조건

| 설정값 | 의미 | 기본값/제약 |
|---|---|---|
| 기준 종목 (`ma0.stock`) | 구간 판정, RSI, 정배열 판단에 쓰는 대표 종목 | 기본값 `QQQ` |
| 단기 이동평균 기간 (`maAPeriod`) | 첫 번째 이동평균 기간 | 기본값 20일, 1~250일 |
| 장기 이동평균 기간 (`maBPeriod`) | 두 번째 이동평균 기간 | 기본값 60일, 1~250일 |
| RSI 사용 여부 (`rsiEnabled`) | RSI 조건으로 매수 안내를 제한할지 여부 | 기본값 꺼짐 |
| 정배열 사용 여부 (`alignmentEnabled`) | `maAPeriod` 이평선이 `maBPeriod` 이평선보다 높을 때만 매수할지 여부 | 기본값 꺼짐 |

표준 이동평균 기간인 20일, 60일, 120일은 주가 스냅샷에 저장된 값을 우선 사용합니다. 그 외 기간은 기준 종목의 과거 가격을 불러와 최근 N일 종가의 단순 이동평균으로 계산합니다.

### ma1/ma2/ma3: 구간별 종목과 조건

| 구간 | 설정값 | 의미 |
|---|---|---|
| 구간 1 (`ma1`) | 종목, RSI 기준값, 중간익절 여부, 중간익절 목표 수익률 | 기준 종목 현재가가 두 이동평균선보다 높을 때 사용 |
| 구간 2 (`ma2`) | 종목, RSI 기준값, 중간익절 여부, 중간익절 목표 수익률, `splitCount` | 기준 종목 현재가가 두 이동평균선 사이에 있을 때 사용 |
| 구간 3 (`ma3`) | 종목, RSI 기준값, 중간익절 여부, 중간익절 목표 수익률 | 기준 종목 현재가가 두 이동평균선보다 낮을 때 사용 |

구간별 기본 종목은 구간 1 `QQQ`, 구간 2 `QLD`, 구간 3 `TQQQ`입니다. 전략 생성 UI는 `ma1`, `ma2`, `ma3` 사이의 중복 종목 선택을 막고, 최종 저장 전에도 중복 여부를 다시 검증합니다. 이는 구간별 보유·익절 안내가 서로 섞이지 않도록 하기 위한 장치입니다.

`ma2.splitCount`는 현재 MA Strategy의 핵심 구간 판정에는 영향을 주지 않으며, 구간 2 설정에 보존되는 고정값에 가깝습니다.

### RSI와 중간익절 입력 범위

| 설정값 | 의미 | 기본값/제약 |
|---|---|---|
| 구간별 RSI 기준값 (`rsiThreshold`) | RSI 사용 시, 해당 구간에서 매수를 허용할 최대 RSI | 기본값 30, 입력 범위 0~100 |
| 중간익절 사용 여부 (`takePartialProfit`) | 목표 수익률 도달 시 중간익절 안내를 보여줄지 여부 | 기본값 꺼짐 |
| 중간익절 목표 수익률 (`partialProfitTargetPct`) | 평단 대비 몇 % 이상 오르면 익절 안내를 낼지 | 기본값 10%, 입력 범위 1~100 |

RSI 기능이 꺼져 있으면 저장되는 전략에는 구간별 RSI 기준값이 빠질 수 있습니다. 중간익절이 꺼져 있으면 목표 수익률도 저장되지 않을 수 있습니다.

## 3. 구간(Section) 판정 로직 (Section Determination)

구간 판정은 `determineActiveSection` 흐름과 서버 공유 함수의 `determineMaActiveSectionFromValues` 규칙을 따릅니다.

### 사용하는 값

| 기호 | 의미 |
|---|---|
| `P` | 기준 종목 `ma0.stock`의 현재가 |
| `MA_A` | `maAPeriod` 기간의 기준 종목 이동평균 |
| `MA_B` | `maBPeriod` 기간의 기준 종목 이동평균 |
| `High` | `max(MA_A, MA_B)` |
| `Low` | `min(MA_A, MA_B)` |

앱은 `maAPeriod`가 항상 `maBPeriod`보다 짧다거나, `MA_A`가 항상 `MA_B`보다 낮거나 높다고 가정하지 않습니다. 두 이동평균 중 큰 값을 상단선, 작은 값을 하단선으로 삼습니다. 따라서 정배열과 역배열 모두에서 동일한 방식으로 구간을 판정할 수 있습니다.

### 판정 공식

| 조건 | 활성 구간 | 매수 후보 |
|---|---|---|
| `P > High` | 구간 1 | `ma1.stock` |
| `Low <= P <= High` | 구간 2 | `ma2.stock` |
| `P < Low` | 구간 3 | `ma3.stock` |

경계값은 구간 2에 포함됩니다. 즉, 기준 종목 현재가가 두 이동평균선 중 하나와 정확히 같으면 구간 2입니다.

### 예외 케이스

- 기준 종목 현재가가 없거나, 0 이하이거나, 유효한 숫자가 아니면 활성 구간을 판정하지 않습니다.
- 두 이동평균값 중 하나라도 없거나, 0 이하이거나, 유효한 숫자가 아니면 활성 구간을 판정하지 않습니다.
- 표준 기간(20/60/120)이 아닌 기간은 가격 이력으로 직접 계산합니다. 이력이 부족해 이동평균을 계산할 수 없으면 해당 이동평균값은 0이 되고, 결과적으로 활성 구간은 `null`이 됩니다.
- 활성 구간이 `null`이면 대시보드에서는 구간 확인 중 상태가 표시될 수 있고, 알림 요약에서는 매수 구간 라인이 생략됩니다.

## 4. 보조지표 조건 (Indicator Rules - RSI & 정배열)

RSI와 정배열은 **구간을 바꾸지 않습니다**. 먼저 활성 구간을 판정한 뒤, 해당 구간의 매수 안내를 실제 매수 후보로 보여줄지, 아니면 관망으로 보여줄지만 결정합니다.

### RSI 조건

RSI 기능은 `ma0.rsiEnabled`가 `true`일 때만 작동합니다. RSI 값은 구간별 종목이 아니라 **기준 종목 `ma0.stock`의 RSI**를 사용합니다.

작동 순서는 다음과 같습니다.

1. 활성 구간이 1, 2, 3 중 하나인지 확인합니다.
2. 활성 구간에 해당하는 RSI 기준값을 가져옵니다.
   - 구간 1: `ma1.rsiThreshold`
   - 구간 2: `ma2.rsiThreshold`
   - 구간 3: `ma3.rsiThreshold`
3. 기준 종목의 현재 RSI를 확인합니다.
4. RSI가 없거나 유효하지 않으면 중립값 50을 대신 사용합니다.
5. `현재 RSI > 구간별 RSI 기준값`이면 RSI 조건 미충족입니다.
6. `현재 RSI <= 구간별 RSI 기준값`이면 RSI 조건을 충족한 것으로 봅니다.

비즈니스 의미는 "RSI가 기준값보다 높으면 아직 충분히 낮은 가격대가 아니므로 매수를 쉬고 관망한다"입니다. 기본 기준값이 30이므로, 기본 설정에서는 기준 종목 RSI가 30 이하일 때만 RSI 조건을 통과합니다.

RSI 기능이 꺼져 있으면 RSI 값과 기준값은 매수 안내에 영향을 주지 않습니다. RSI 기준값이 저장되어 있지 않은 예외 상황에서도 RSI 조건은 매수를 막지 않습니다.

### 정배열 조건

정배열 조건은 `ma0.alignmentEnabled`가 `true`일 때만 작동합니다. 앱은 선택된 두 이동평균선을 다음처럼 비교합니다.

```text
정배열 충족: MA_A > MA_B
정배열 미충족: MA_A <= MA_B
```

예를 들어 `maAPeriod=20`, `maBPeriod=60`이면 20일선이 60일선보다 높아야 정배열 충족입니다. `maAPeriod=60`, `maBPeriod=120`처럼 다른 표준 기간을 선택한 경우에는 60일선과 120일선을 비교합니다. 현재 MA Strategy의 정배열 조건은 **사용자가 선택한 두 이동평균선만 비교**하며, 20일·60일·120일 세 선이 모두 순서대로 배열되어야 한다는 의미는 아닙니다.

정배열 기능이 꺼져 있으면 이동평균선의 배열 상태는 매수 안내에 영향을 주지 않습니다.

### RSI와 정배열이 함께 켜진 경우

RSI와 정배열은 독립적으로 계산됩니다.

- 둘 다 충족하면 활성 구간의 종목을 매수 대상으로 안내합니다.
- RSI만 미충족이면 "관망 (RSI 조건 미충족)"으로 안내합니다.
- 정배열만 미충족이면 "관망 (정배열 미충족)"으로 안내합니다.
- 둘 다 미충족이면 "관망 (정배열 미충족, RSI 조건 미충족)"으로 안내합니다.

이 관망 판단은 매수 라인에만 영향을 줍니다. 중간익절 조건은 별도로 계산되므로, 매수는 관망이어도 중간익절 라인은 함께 표시될 수 있습니다.

## 5. 부분 익절 및 매도 로직 (Partial Profit & Sell Rules)

중간익절 로직은 `collectMaPartialProfitLine` 규칙을 따릅니다. 이름은 "Partial Profit"이지만, 현재 앱의 라이브 요약에서는 실제 주문을 자동 실행하지 않고 **중간익절 안내 라인**을 만드는 역할입니다.

### 중간익절 검사 대상

앱은 활성 구간 하나만 보는 것이 아니라 `ma1`, `ma2`, `ma3` 세 구간을 모두 확인합니다. 즉, 오늘의 활성 구간이 1이어도 구간 2 또는 구간 3 종목이 이미 보유 중이고 목표 수익률에 도달했다면 중간익절 안내가 나올 수 있습니다.

각 구간은 다음 조건을 모두 만족해야 중간익절 검사 대상이 됩니다.

1. 해당 구간의 `takePartialProfit`이 `true`입니다.
2. `partialProfitTargetPct`가 존재하고 0보다 큽니다.
3. 해당 구간의 종목 코드가 존재합니다.
4. 거래 기록 기준으로 해당 종목 보유 수량이 0보다 큽니다.
5. 해당 종목 평균 매입가가 0보다 큽니다.
6. 현재가가 0보다 큽니다.

하나라도 만족하지 않으면 중간익절 라인은 생성되지 않습니다.

### 보유 수량과 평단 계산

앱은 포트폴리오의 거래 기록을 시간순으로 정리해 현재 보유 내역을 계산합니다.

- 매수 거래는 `매수가 × 수량 + 매수 수수료`를 총원가에 더합니다.
- 매도 거래는 이동평균법 기준의 평단을 사용해 보유 수량과 총원가를 줄입니다.
- 현재 평단은 `남은 총원가 / 남은 수량`입니다.
- 보유 수량이 0에 가까워지면 수량과 원가는 0으로 정리됩니다.

중간익절 판단은 이 보유 내역의 `quantity`와 `avgPrice`를 사용합니다.

### 목표 수익률 도달 공식

| 기호 | 의미 |
|---|---|
| `CurrentPrice` | 해당 구간 종목의 현재가 |
| `AvgPrice` | 해당 종목의 현재 평균 매입가 |
| `TargetPct` | 해당 구간의 중간익절 목표 수익률 |

```text
수익률(%) = ((CurrentPrice - AvgPrice) / AvgPrice) × 100
```

중간익절 라인은 다음 조건에서 생성됩니다.

```text
수익률(%) >= TargetPct
```

예를 들어 구간 2 종목의 평단이 100달러이고 현재가가 110달러이며 목표 수익률이 10%이면, 수익률이 10%이므로 중간익절 안내가 생성됩니다.

### 생성되는 안내 라인

조건을 만족하면 앱은 다음 정보를 가진 중간익절 라인을 만듭니다.

| 값 | 의미 |
|---|---|
| `section` | 어느 구간의 중간익절인지 |
| `stock` | 익절 대상 종목 |
| `quantity` | 현재 보유 수량 |

표시할 때 수량은 반올림되어 "구간 N 중간익절: 종목 X주" 형태로 노출됩니다.

중요한 예외가 있습니다. 현재 라이브 앱의 `collectMaPartialProfitLine`은 해당 종목의 **현재 보유 수량 전체**를 안내 수량으로 반환합니다. 즉, 코드상으로는 수량의 일부 비율을 계산해 나누어 파는 로직이 아니라, 목표 수익률에 도달한 종목에 대해 보유 수량을 안내하는 방식입니다. 실제 매도 주문은 사용자가 직접 판단해 증권사 앱에서 실행해야 합니다.

백테스트 스크립트는 구간별 포지션을 따로 추적해 목표 수익률 도달 시 해당 구간 포지션을 매도하는 시뮬레이션을 수행합니다. 반면 대시보드와 알림의 라이브 로직은 거래 기록에서 계산한 현재 보유 종목 기준으로 중간익절 안내 라인을 생성합니다.

## 6. 대시보드와 알림에서의 최종 표시 규칙

MA Strategy의 일별 실행 요약은 다음 순서로 조합됩니다.

1. 포트폴리오 이름, 전략명, 알람 시간을 표시합니다.
2. 활성 구간이 유효하면 구간별 매수 또는 관망 라인을 표시합니다.
3. 중간익절 조건을 만족한 구간이 있으면 중간익절 라인을 추가합니다.
4. 마지막에는 "오늘 주문 요약은 앱에서 확인해 주세요." 안내를 붙입니다.

매수·관망 라인의 우선순위는 다음과 같습니다.

| 조건 | 표시 |
|---|---|
| RSI와 정배열이 모두 미충족 | 구간 N: 관망 (정배열 미충족, RSI 조건 미충족) |
| 정배열만 미충족 | 구간 N: 관망 (정배열 미충족) |
| RSI만 미충족 | 구간 N: 관망 (RSI 조건 미충족) |
| 둘 다 통과 또는 둘 다 꺼짐 | 구간 N: 해당 구간 종목 매수 |

여기서도 앱은 자동 주문을 실행하지 않습니다. 표시되는 내용은 사용자가 오늘의 주문을 직접 확인하고 입력하기 위한 참고 가이드입니다.

## 7. 주요 예외와 안전 규칙 요약

- 구간 판정은 기준 종목 `ma0.stock`의 현재가와 두 이동평균값이 모두 유효할 때만 가능합니다.
- 현재가 또는 이동평균값이 없거나 0 이하이면 활성 구간은 없습니다.
- 두 이동평균선의 위아래 순서가 바뀌어도 구간 판정은 `max`와 `min`으로 안정적으로 동작합니다.
- 현재가가 이동평균선 경계와 같으면 구간 2입니다.
- RSI와 정배열은 활성 구간 자체를 바꾸지 않고, 매수 안내를 관망으로 바꾸는 필터입니다.
- RSI 값이 없으면 중립값 50을 사용합니다.
- 중간익절은 활성 구간과 별개로 세 구간 모두 검사합니다.
- 중간익절 목표 수익률이 없거나 0 이하이면 해당 구간의 중간익절은 비활성으로 봅니다.
- 전략 생성 UI는 `ma1`, `ma2`, `ma3`의 종목 중복을 막습니다.
- 다른 전략(`multiSplit`, `noStopMultiSplit`, `vrBand`) 전용 필드가 없는 포트폴리오는 대시보드와 알림에서 MA Strategy로 취급됩니다.
