# Smart Split(다분할 매매) 전략 백서 — 공식과 비즈니스 해석

> 본 문서는 구현 코드가 아니라, 제품·고객 설명용으로 필요한 **변수 정의**, **핵심 공식**, **비즈니스적 의미**만 정리합니다.  
> 외부 전략(예: 특정 유튜버·서적의 무한매수법 버전)과의 역사적·개념적 유사성은 별도 조사(NotebookLM 등)로 검증하는 것을 전제로 합니다.

---

## 1. 한 줄 정의

**Smart Split**은 (1) 미리 정한 총 투자 한도 안에서 **고정 단위로 여러 번 분할 매수**하고, (2) **평단가 대비 목표 수익률**에 도달하면 보유 물량을 **메인·중간 익절**로 나누어 수익을 실현하며, (3) 시드 부족·데이터 이상 등 **방어 상태**에서는 기계적 추가 매수를 중단하거나 요약 안내만 제공하는 전략입니다.

---

## 2. 기호와 변수

| 기호 | 의미 |
|------|------|
| \(A\) | **1회 매수금**(한 번에 배정하는 매수 예산의 기준 단위). |
| \(N\) | **총 분할 횟수**(`totalSplitCount`). |
| \(S\) | **총 시드(총 투자 상한의 파생값)**. |
| \(I\) | **현재까지 투입된 원가**(거래 장부 기준, 수수료 포함 누적). |
| \(R\) | **남은 시드(가용 잔액 상한)**. |
| \(B\) | **이번 회차에 실제로 쓸 매수 예산(트렌치)**. |
| \(q\) | **현재 보유 수량**. |
| \(\bar{p}\) | **현재 평단가**(평균 매입 단가). |
| \(P\) | **현재가**(실행 시점 시세 스냅샷). |
| \(r_{\mathrm{fee}}\) | **매수 수수료율(%)** — LOC 단가 산출에만 반영합니다. |
| \(L\%\) | **적용 LOC 비율(%)** — 이번 회차 예산 중 평단가 매수(LOC)에 먼저 배정할 비중. |
| \(r_{\mathrm{main}}\%\) | **메인 익절 물량 비율(%)** — 전체 보유 수량 대비 메인 익절로 보낼 비율. |
| \(r_{\mathrm{risk}}\%\) | **위험 관리(포지션 축소) 비율(%)** — 보유 수량 대비 줄일 목표 비율. |
| \(g_{\mathrm{main}}\%\), \(g_{\mathrm{mid}}\%\) | 각각 **메인·중간 익절 목표 수익률(%)** — 모두 **평단가 대비**입니다. |
| \(\varepsilon\) | **수량 0에 가까운지 판단하는 허용 오차** — “사실상 무포지션” 판정에만 사용. |

**비즈니스 해석:** 투자자가 직관적으로 쓰는 “총 시드는 얼마인가?”는 단독 입력칸이 아니라 **\(S = A \times N\)** 로 고정됩니다. 전략은 무한 증액이 아니라 **정해진 상한 안의 분할 운용**입니다.

---

## 3. 시드·잔액·회차 예산

### 3.1 총 시드

\[
S = A \times N
\]

**해석:** “몇 번 나누어 넣을지”와 “한 번에 얼마씩 넣을지”가 곱해져 **전략이 허용하는 총 투입 상한**이 됩니다.

### 3.2 남은 시드(가용 잔액)

\[
R = S - I,\quad R \ge 0 \text{ 으로 클램프(음수는 비즈니스적으로 무의미)}
\]

**해석:** 아직 주문으로 소비하지 않은, 이론상 더 넣을 수 있는 금액입니다.

### 3.3 이번 회차 매수 예산(트렌치)

\[
B = \min(A,\, R)
\]

**해석:** 남은 돈이 많아도 **한 번에 \(A\)를 넘지 않습니다.** 마지막 회차만 \(R < A\)일 수 있어 \(B = R\)이 됩니다.  
이 제한은 “분할이라는 규율”을 깨지 않게 하는 핵심 안전장치입니다.

---

## 4. 거래 장부와 평단가(개념)

시간순으로 정렬된 거래에 대해:

- 매수 한 건의 원가 증가: \(\Delta I = p \times \Delta q + |\text{수수료}|\)
- 매도 시에는 **매도 직전 평단**으로 실현손익을 정산하고, 잔여 수량·잔여 원가를 갱신합니다.
- 전량 매도 시 보유·원가를 0으로 리셋합니다.

**해석:** 이후 모든 LOC·익절 가격은 **\(\bar{p}\)** 를 앵커로 삼습니다. 장부가 틀리면 전략 전체가 틀어지므로, **거래의 시간 순서 보존**이 필수입니다(같은 날 여러 건이면 원 입력 순서 유지).

---

## 5. LOC 비율 \(L\%\) (기본값 + 조건부 프리셋)

1. **기본:** 사용자가 설정한 `baseLocRatio`를 출발점으로 둡니다.
2. **RSI 조건:** RSI가 임계값 **미만**이면 (과매도 구간으로 간주) 해당 규칙의 LOC 비율 후보를 추가합니다.
3. **이동평균 정배열:** 단기 이평 > 장기 이평이면 해당 규칙의 LOC 비율 후보를 추가합니다.
4. 후보가 여럿이면 **가장 큰 LOC 비율**을 채택합니다.

\[
L\% = \max(\text{적용 가능한 후보들})
\]

**해석:** 시장이 “더 방어적으로 살 타이밍”으로 판단될수록 LOC(평단가 근처) 쪽으로 예산을 기울일 수 있습니다. 반대로 조건이 안 맞으면 기본 비중으로 돌아갑니다.

---

## 6. 분할 매수: MOC 후 LOC (단가·수량)

### 6.1 예산 쪼개기

\[
B_{\mathrm{LOC}} = B \times \frac{L}{100},\qquad
B_{\mathrm{MOC}} = B - B_{\mathrm{LOC}}
\]

**해석:** “이번 회차 예산”을 LOC 몫과 MOC 몫으로 나눕니다. **별도 `mocRatio` 필드는 없고**, MOC 몫은 자동으로 \(100 - L\)입니다.

### 6.2 단가(유닛 코스트)

\[
p_{\mathrm{MOC}} = P \times k,\quad k = 1.15
\]

\[
p_{\mathrm{LOC}} = \bar{p} \times \left(1 + \frac{r_{\mathrm{fee}}}{100}\right)
\]

**비즈니스 해석:**

- **MOC:** 종가 체결 등 가격 변동을 흡수하기 위해 **현재가의 115%** 를 “한 주를 사려면 준비해야 할 단가 상한”처럼 취급합니다. (과잉 체결·예산 초과를 줄이는 보수 쿠션.)
- **LOC:** 지정가를 **현재 평단가**로 표시하고, 수수료만 단가에 더해 “실질 매수 단가”를 잡습니다.

### 6.3 수량(정수 주, 바닥 함수)

\[
q_{\mathrm{MOC}} = \left\lfloor \frac{B_{\mathrm{MOC}}}{p_{\mathrm{MOC}}} \right\rfloor_{\ge 0},\quad
\text{사용액}_{\mathrm{MOC}} = q_{\mathrm{MOC}} \times p_{\mathrm{MOC}}
\]

\[
B_{\mathrm{LOC,잔여}} = B - \text{사용액}_{\mathrm{MOC}}
\]

\[
q_{\mathrm{LOC}} = \left\lfloor \frac{B_{\mathrm{LOC,잔여}}}{p_{\mathrm{LOC}}} \right\rfloor_{\ge 0}
\]

**해석:** **MOC를 먼저 채우고**, 남은 예산으로 LOC를 채웁니다. “LOC 비율로 잘랐다고 해서 두 주문이 정확히 그 비율만큼만 쓰인다”는 뜻이 아니라, **정수 주와 단가·버퍼 때문에 실제 체결 비중은 약간 변동**할 수 있습니다.

---

## 7. 분할 익절: 물량과 목표가

### 7.1 메인·중간 익절 수량

\[
q_{\mathrm{main,raw}} = q \times \frac{r_{\mathrm{main}}}{100}
\]

\[
q_{\mathrm{main}} = \mathrm{round\_to\_nonnegative\_int}(q_{\mathrm{main,raw}}),\quad
q_{\mathrm{main}} = \min(q_{\mathrm{main}},\, q)
\]

\[
q_{\mathrm{mid}} = \max(0,\, q - q_{\mathrm{main}})
\]

**해석:** 메인 익절을 먼저 **반올림해 정수 주**로 확정하고, 남은 전량을 중간 익절로 보냅니다. UI에 보이는 “중간 = 100% − 메인%”는 **개념적 안내**이며, 반올림 때문에 **정확히 \(100 - r_{\mathrm{main}}\%\)와 1주 차이**가 날 수 있습니다.

### 7.2 익절 목표가(평단가 기준)

\[
p^{\ast}_{\mathrm{main}} = \bar{p} \times \left(1 + \frac{g_{\mathrm{main}}}{100}\right)
\]

\[
p^{\ast}_{\mathrm{mid}} = \bar{p} \times \left(1 + \frac{g_{\mathrm{mid}}}{100}\right)
\]

**해석:** 익절 트리거는 “오늘 종가”가 아니라 **현재 장부의 평단가 대비 몇 % 올랐는가**로 설명하는 것이 맞습니다.

### 7.3 위험 관리(포지션 축소) 수량

\[
q_{\mathrm{risk}} = \left\lfloor q \times \frac{r_{\mathrm{risk}}}{100} \right\rfloor_{\ge 0}
\]

**해석:** 이 레이어는 **가격 기준 손절 라인 계산**과는 별개로, “위험 구면에서 몇 주를 줄일지”를 수량으로 제시합니다. 실제 주문 UX에서는 **시드 부족·소진 상태**에서만 이 줄을 노출하는 등 화면 정책이 있을 수 있습니다.

---

## 8. 방어 상태: 매수 가이드 중단 조건(비즈니스 의미)

아래 중 하나라면 **LOC/MOC 수량 가이드를 만들지 않고** 기본 상태만 반환합니다.

| 상태 | 판정(개념) | 고객 메시지 방향 |
|------|------------|------------------|
| 첫 매수 | \(q \le \varepsilon\) | 평단가가 없으므로 “1회 매수금 기준 첫 진입” 안내. |
| 데이터 오류 | \(q > \varepsilon\) 인데 \(\bar{p}\) 비정상 | 평단가 불일치 — 추가 매수 가이드 중단. |
| 시드 소진 | \(I \ge S\) | 더 이상 전략 상한 내 분할 매수 없음. |
| 저예산 | \(0 < R < A\) | 1회분 예산을 채울 수 없음 — “매수금 부족” 방어. |

**해석:** Smart Split은 “항상 어떤 숫자라도 내놓는 계산기”가 아니라, **전략 전제가 깨지면 침묵하거나 요약만** 하는 편이 안전합니다.

---

## 9. 목표 수익률 입력의 허용 범위(개요)

- \(g_{\mathrm{main}}\%\)와 \(g_{\mathrm{mid}}\%\)는 각각 제품 정책상 **최소·최대 구간으로 클램프**됩니다.
- **해석:** 극단값이 들어와도 엔진이 무너지지 않게 하고, 고객에게도 “현실적인 구간”만 노출하기 위함입니다.

---

## 10. 모바일 상세 설명용 시각화 아이디어(선택)

텍스트만으로 부족할 때, 아래 정도의 단순 도표가 이해에 도움이 됩니다.

1. **시드 막대:** \(I\) / \(S\) 진행률, \(R\) 잔여를 한 줄 바 차트로.
2. **회차 예산:** \(B = \min(A,R)\) 를 “이번에 쓸 수 있는 칸”으로 표현.
3. **LOC vs MOC:** 한 트렌치 안에서 예산이 두 주문으로 나뉘는 개념도(비율은 대략치).
4. **익절 2단:** \(\bar{p}\) 위에 \(p^{\ast}_{\mathrm{mid}}\), \(p^{\ast}_{\mathrm{main}}\) 두 개의 수평선(개념 스케치).

---

## 11. 고객에게 말하지 말아야 할 함정(내부용 체크리스트)

- “손절가 = ?”처럼 **단일 손절 목표가**를 약속하지 말 것 — 제품은 **위험 관리 수량** 중심입니다.
- “MOC 비율을 따로 입력한다”고 말하지 말 것 — **항상 \(100 - L\)** 입니다.
- “중간 익절 %가 항상 메인의 여분과 정확히 같다”고 말하지 말 것 — **정수 반올림**이 개입합니다.
