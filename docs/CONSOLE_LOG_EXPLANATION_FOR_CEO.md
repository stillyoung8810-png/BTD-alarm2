# 로그아웃 후 재로그인 시 콘솔 로그 설명 (비개발자용)

> **상황**: 로그아웃 후 다시 로그인했을 때 브라우저 개발자 도구에 찍힌 로그들입니다.  
> **추정**: 처음 자동 로그인 상태에서는 최신 종가가 아직 반영되지 않았고, 재로그인을 하면서 새로 데이터를 불러와서 최신 종가가 반영된 과정으로 보입니다.

---

## 전체 흐름 (한 줄 요약)

**“다시 로그인하면서, 앱이 주가 데이터를 처음부터 다시 불러와서 저장하고, 부족한 종목은 서버에서 채워 넣고, 그날 매매 요약과 푸시 알림까지 정리한 과정”**입니다.

---

## 단계별로 보면 (회장님께 드리는 설명)

### 1. 주가 데이터 불러오기 시작
- **로그**: `[App] IndexedDB 초기 데이터 로딩 시작`
- **의미**: 로그인 직후, 앱이 “지금부터 주가 데이터를 준비한다”고 시작한 단계입니다.  
  사용자 기기 안의 저장소(IndexedDB)에 넣을 데이터를 불러옵니다.

### 2. 여러 종목의 주가 데이터 저장
- **로그**: `[IndexedDB] 216개 주가 데이터 저장 완료` (또는 215개, 138개 등, 여러 번)
- **의미**:  
  - 각 종목마다 **과거 일별 주가(종가 등)** 를 일정 개수(예: 216일치)만큼 불러와서  
  - 사용자 기기 안에 **저장이 완료되었다**는 뜻입니다.  
  - 숫자가 여러 번 나오는 것은 **종목이 여러 개**이기 때문입니다.

### 3. 초기 데이터 로딩 완료
- **로그**: `[App] IndexedDB 초기 데이터 로딩 완료`
- **의미**:  
  “처음에 필요한 주가 데이터 불러오기와 저장”이 **일단 끝났다**는 단계입니다.  
  이 시점부터 대시보드·시세 등에서 사용할 기본 데이터가 준비된 상태입니다.

### 4. 차트 경고 (기능 문제 아님)
- **로그**: `The width(-1) and height(-1) of chart should be greater than 0...`
- **의미**:  
  시세 화면의 **차트**를 그릴 때, “차트를 넣을 칸의 크기가 아직 잡히지 않았다”는 **라이브러리 경고**입니다.  
  화면이 다 뜬 뒤에는 보통 정상적으로 그려지며, **주가 반영이나 로그인 과정과는 무관**한 UI 이슈입니다.

### 5. 푸시 알림(FCM) 준비
- **로그**: `[FCM] saveFCMToken called.` → `Firebase initialized successfully` → `FCM token saved successfully`
- **의미**:  
  로그인한 사용자에게 **알람 푸시를 보내려면**, 이 기기의 “토큰”을 서버에 등록해야 합니다.  
  재로그인하면서 **그 토큰을 다시 등록해 두었다**는 뜻입니다.  
  → 이후 알람 시간에 푸시가 정상적으로 갈 수 있는 상태가 된 것입니다.

### 6. 일부 종목은 “기기에는 없어서 서버에서 가져옴”
- **로그**:  
  `[calculateTechnicalIndicators] TSLA: IndexedDB 데이터 부족, Supabase에서 가져오기`  
  (NVDA, GGLL, GOOGL, PLTR, COIN, MSTR 등 동일)
- **의미**:  
  - **TSLA, NVDA, GOOGL** 같은 종목은 **PRO/프리미엄 구독 사용자**용으로 제공하는 종목입니다.  
  - 이 종목들의 과거 주가가 **아직 기기 안에 충분히 없었기 때문에**,  
    “기기 저장소(IndexedDB)에는 부족하니 **서버(Supabase)** 에서 가져오겠다”는 동작입니다.  
  - 가져온 뒤 다시 `[IndexedDB] 215개 주가 데이터 저장 완료` 같은 로그가 나오면,  
    **그 종목도 기기 안에 저장이 완료된 것**입니다.  
  → **“재로그인 후 최신 종가가 반영된다”**고 하신 부분은,  
    이 단계에서 **서버에서 최신 데이터를 받아와서 채워 넣은 결과**로 이해하시면 됩니다.

### 7. 당일 매매 요약 저장
- **로그**: `[DailyExecution] summary upserted for 2026-02-13`
- **의미**:  
  “오늘(2026-02-13) 기준으로, **매매 실행 요약(일별 실행 요약)** 을 서버에 한 번 저장/갱신했다”는 뜻입니다.  
  재로그인 후 **최신 포트폴리오·주가를 반영한 요약**이 저장된 것으로 보시면 됩니다.

### 8. 푸시 토큰 저장 완료
- **로그**: `[FCM] FCM token saved successfully`
- **의미**:  
  이 기기의 **푸시 알림용 토큰**이 서버에 정상적으로 저장되었습니다.  
  알람 시간에 이 기기로 푸시가 갈 수 있는 상태입니다.

---

## 회장님께 말씀드리실 때 요약 문장

- **“로그아웃 후 다시 로그인하신 뒤에 나온 로그들은, 앱이 주가 데이터를 처음부터 다시 불러와서 기기에 저장하고, PRO 종목처럼 기기에 없던 건 서버에서 받아와서 채우고, 오늘자 매매 요약이랑 푸시 알림 등록까지 마친 과정입니다. 처음 자동 로그인 때는 이 흐름이 다 돌기 전이거나 예전 데이터만 보였을 수 있고, 재로그인하면서 이 과정이 다시 실행되면서 최신 종가가 반영된 걸로 보시면 됩니다.”**
